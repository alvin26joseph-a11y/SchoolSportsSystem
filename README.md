# School Sports Event Management System

A Java desktop application built to organize school sports events, streamline participant registrations, track tournament schedules, and record scores.

---

## Features

- **Event Scheduling**: Organize sports events, manage category schedules, and track match fixtures.
- **Student & Team Registration**: Log athlete details, assign house/team affiliations, and manage event entries.
- **Score & Standings Management**: Record scores, track event winners, and automatically calculate aggregate house points.
- **Object-Oriented Architecture**: Modular Java design ensuring clean data structure separation and maintainability.

---

## Tech Stack

- **Language**: Java (JDK 8+)
- **IDE**: NetBeans IDE
- **Build Tool**: Apache Ant (`build.xml`)

---
